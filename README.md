Forecasts how many people watch Grand Theft Auto VI live on Twitch in each hour of its release day, as five quantiles an hour. `main.py` (Python 3.13, standard library only) reads one case from `/input`, fits a scale-conditioned model to the case's own comparable launches — a least-squares line of each hour's log-ratio to hour 1 against log hour-1 over the 18 closest launches, with residual-based quantile spreads — and writes the forecast to `/output`. Deterministic, offline, well inside the 8-second cap.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
